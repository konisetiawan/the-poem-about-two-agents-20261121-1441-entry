# The Rope — The poem about two agents agreeing

[![make.fun competition](https://img.shields.io/badge/make.fun-The%20poem%20about%20two%20agents%20agreeing-4c6c72)](https://make.fun/competitions/the-poem-about-two-agents-20261121-1441)

This program writes a short poem about two agents agreeing on one plan to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory.
